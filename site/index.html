Driveway

Use Windows (NTFS) and Linux (ext) drives on your Apple Silicon Mac.

Free and open source. No account, no licence key, nothing to buy.

Apple Silicon (M1 or later) · macOS 15.4 or later · Step-by-step guide

Macs can open drives formatted on Windows, but they can't save anything to them. Driveway is a free alternative to Tuxera NTFS for Mac and Paragon NTFS for anyone who can't buy them or doesn't want to pay for them. Plug in a drive and Driveway mounts it so you can copy, rename and delete files in Finder as usual. It can also check, repair, back up and format drives.

Driveway doesn't contain a filesystem driver of its own. It sets up and runs well-known free tools for you: macFUSE, ntfs-3g and e2fsprogs.

What it does

  • Plug in and write

    NTFS drives mount read/write by themselves, whether or not the Driveway window is open. A drive that was already plugged in when you logged in is taken over within a few seconds.

  • Disk Manager

    One window lists your drives, with three tabs: Info, Check & Repair and Format.

  • Setup does the installing

    The Setup screen shows what your Mac can do, what's missing, and installs it for you.

  • Your files come first

    If Windows didn't shut a drive down properly, Driveway mounts it read-only and tells you, instead of writing to it and risking your files. One click, Fix & mount read/write, repairs it when you're ready.

  • Back up before a repair

    Back up first saves a complete copy of the drive to a file, with a progress bar.

  • Linux drives too

    ext2, ext3 and ext4 drives open read-only and show up in Finder's sidebar.

What works on your Mac

What Driveway can do depends on your version of macOS and on your Mac's security settings. You don't need to work this out yourself: Setup checks your Mac and shows each feature as ready, missing something, or not available.

Feature macOS 15, standard security macOS 26 or later, standard security Kernel extensions already allowed
See and copy files from NTFS drives Yes Yes Yes
Save files to NTFS drives No Expected, not yet tested Yes
Check & Repair, Back up first (NTFS) Yes Yes Yes
Format as exFAT or FAT32 Yes Yes Yes
Format as NTFS No Expected, not yet tested Yes
Linux (ext) drives No Expected, not yet tested Yes

Standard security

This is how every Mac comes from the factory. You almost certainly have it unless you changed it yourself in Recovery.

Kernel extensions already allowed

Your Mac was set up earlier to accept third-party system extensions, usually because Tuxera, Paragon or another disk tool was installed on it at some point. If that's the case, Driveway can save files to NTFS drives on any supported macOS.

Why macOS 15 can't save files with standard security

On a Mac with standard security, macFUSE uses Apple's new FSKit system. FSKit is broken on recent macOS 15.7 updates: every attempt to mount a drive fails. When Driveway sees this, Setup shows Write to NTFS drives as Not available on this Mac yet, and your drives stay readable as usual. Driveway tries again after each macOS or macFUSE update.

macOS 26 and later

Nobody has tested Driveway on macOS 26 or later yet. Try it first with a drive that has nothing important on it, and please tell us how it went, whether it worked or not.

Driveway never asks you to lower your Mac's security, and it never changes security settings itself.

Install

The whole process takes about 20 minutes, most of it waiting for downloads.

  • A Mac with Apple Silicon (M1 or later)
  • macOS 15.4 or later
  • An administrator account
  • An internet connection

  1. Remove Tuxera or Paragon, if you have them

    If Tuxera NTFS for Mac or Paragon NTFS (or Paragon extFS) is installed, remove it first, using the uninstaller that came with it. These programs grab drives before Driveway can. If you've never installed them, skip this step.

  2. Install Homebrew

    Homebrew is a free tool that installs software from the command line. Driveway uses it to install macFUSE and ntfs-3g for you. You only need to do this once.

    Open Terminal (press ⌘ Space, type Terminal and press Return), paste this line and press Return:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    When it asks for your Password, type the password you use to log in to your Mac. Nothing appears on screen while you type. That's normal. It's finished when you see Installation successful!

  3. Install Driveway

    In Terminal, paste this line and press Return:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/fedar-piashko-vention/Driveway/main/scripts/install.sh)"

    It downloads the latest version of Driveway, puts it in your Applications folder and opens it. If it asks for your Password, type the password you use to log in to your Mac. To update Driveway later, run the same line again.

  4. Run Setup

    Driveway opens with the Setup screen. Click Unlock everything and follow it. It installs what's missing and takes you to the right place in System Settings when macOS needs your approval, including Full Disk Access for the Driveway helper.

  5. Plug in a drive

    Within a few seconds it appears on the desktop and in Finder's sidebar, ready to use. Eject it before you unplug it.

Why Terminal and not a normal download?

Driveway is not signed with a paid Apple developer certificate. If you download it in a web browser, macOS says the app "is damaged and can't be opened", and offers no way to open it anyway. A file downloaded in Terminal doesn't get that check. The app isn't damaged: the warning is about how it's signed, not about what it does. All of Driveway's source code, including the install script, is public for anyone to read. Whether to trust it is your choice.

Prefer to download it yourself?
  1. Go to the latest release and click Driveway-<version>.dmg under Assets to download it.
  2. Open the downloaded file and drag Driveway onto Applications.
  3. Open Terminal, paste this line and press Return. It tells macOS that you trust this copy of Driveway:
    xattr -dr com.apple.quarantine /Applications/Driveway.app
  4. Open Driveway from Applications.

Questions and problems

Is Driveway really free?

Yes. It's open source under the MIT licence. There's no paid version, no trial and no account. The tools it relies on (macFUSE, ntfs-3g and e2fsprogs) are free too.

Is it safe for my files?

Driveway is careful by design. It never writes to a drive that Windows left in an unfinished state without asking you first, it offers a backup before repairs, and it refuses to touch the disk your Mac runs from. Still, no tool is perfect, so keep a backup of anything important, as you would with any drive.

My drive is read-only

Open Driveway and select the drive. The Info tab says why. The most common reasons: Setup isn't finished, or it says Write to NTFS drives is Not available on this Mac yet (see What works on your Mac); Windows didn't shut the drive down cleanly or is hibernating; Full Disk Access is missing; or Tuxera or Paragon is still installed.

macOS says Driveway "is damaged and can't be opened"

You downloaded Driveway in a web browser. The app isn't damaged: macOS says this about apps that aren't signed with a paid Apple developer certificate. Click Cancel, not Move to Bin, then install Driveway with the Terminal line in Install. Or, if Driveway is already in Applications, run the xattr line from "Prefer to download it yourself?" above.

How fast is it?

Fast enough for everyday copying, but slower than Tuxera or Paragon. ntfs-3g is a different kind of driver from theirs, and that's the trade-off for being free. Copying many small files is slower than copying a few large ones.

Does it work on Intel Macs?

It hasn't been tested on Intel Macs, and the download is built for Apple Silicon only.

Something else went wrong

Please open an issue. It helps to include your macOS version and Mac model, what you did and what you expected, and a screenshot of Setup and of the drive's Info tab. The README shows how to attach Driveway's log.

More answers, including how to uninstall, are in the README.
